Cadastro de Alunos

Este é um projeto simples de Cadastro de Alunos feito com JavaScript, HTML, e CSS. O objetivo é criar uma aplicação onde é possível cadastrar, visualizar e excluir alunos.

 🚀 Funcionalidades

- ✅ Cadastro de novos alunos
- 🖊️ Edição de informações dos alunos
- 🗑️ Exclusão de alunos cadastrados
- 💅 Interface simples com HTML e CSS
- 🧑‍💻 100% feito com JavaScript

🎯 Tecnologias Utilizadas

- HTML
- CSS
- JavaScript
